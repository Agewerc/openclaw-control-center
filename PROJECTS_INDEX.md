## Project Status Legend

- 🟢 Active — Currently being worked on
- 🟡 In Progress — Planning or implementation phase
- 🔴 Blocked — Waiting on something
- ✅ Complete — Delivered and approved
- 📦 Archive — Completed, moved to archive

## Workflow for Multiple Projects

### Starting a New Project:
1. Create folder: `projects/active/{project-name}/`
2. Create `PROJECT_BOARD.md` with initial plan
3. Assign lead agent (usually tech-bro for dev work)
4. Add entry to this index

### Project Board Location:
Each project has its own `PROJECT_BOARD.md` at:
```
projects/active/{project-name}/PROJECT_BOARD.md
```

### Archive Completed Projects:
```
projects/archive/{project-name}/
```
